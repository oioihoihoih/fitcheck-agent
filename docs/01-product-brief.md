# Product Brief

## 프로젝트명

`FitCheck Agent: 내 옷장 기준 온라인 의류 구매 검증 AI Agent`

## 배경

온라인에서 옷을 구매할 때 실패하는 이유는 단순히 취향 문제가 아닙니다. 같은 `L` 사이즈라도 브랜드마다 실측이 다르고, 모델 착장 사진은 실제 핏을 과장하거나 왜곡할 수 있습니다. 소재, 두께, 신축성, 봉제, 마감 정보는 상세페이지 이미지 안에 묻혀 있는 경우가 많고, 리뷰에는 유용한 정보가 있지만 구조화되어 있지 않습니다.

사용자는 이미 자신에게 잘 맞는 옷을 알고 있습니다. 문제는 새로 사려는 옷이 그 기준과 얼마나 가까운지 확인하기 어렵다는 점입니다.

## 문제 정의

사용자는 평소 자주 입는 옷의 사이즈, 핏, 소재, 가격대, 디자인 취향을 기준으로 새 상품을 검증하고 싶지만, 상품 정보가 이미지, 표, 리뷰, 착장 사진에 흩어져 있어 매번 직접 비교해야 합니다.

## 목표

FitCheck Agent는 사용자가 등록한 기존 옷장 데이터를 기준으로 구매 후보 상품을 분석하고, 구매 성공 가능성과 위험 요소를 설명합니다.

```text
입력:
- 기존 옷 사진, 라벨, 실측, 착용감 메모
- 후보 상품 URL
- 후보 상품 상세페이지 캡처
- 상품 이미지, 사이즈표 이미지, 소재표 이미지

출력:
- 구매 적합도 점수
- 기존 선호 옷과의 실측 차이
- 소재/핏/가격/디자인 유사도
- 구매 위험 요소
- 자동 보강 후에도 남은 정보 부족 항목
- 최종 구매 판단 리포트
```

## 사용자 시나리오

1. 사용자는 자주 입는 셔츠를 등록한다.
2. 브랜드, 사이즈, 실측, 소재, 착용감 메모를 입력한다.
3. 새로 구매하려는 셔츠의 상품 URL 또는 상세페이지 캡처를 업로드한다.
4. Agent는 상품 페이지에서 사이즈표, 소재표, 착장 이미지, 리뷰 정보를 분리한다.
5. OCR과 parser로 상품 정보를 추출한다.
6. 기존 옷장 데이터와 비교한다.
7. Agent는 "구매해도 좋음", "주의 필요", "비추천"을 근거와 함께 제시한다.

## 핵심 가치

- 구매 실패를 줄인다.
- 사용자의 실제 선호 데이터를 활용한다.
- 상품 사진 중심 추천의 한계를 보완한다.
- LLM을 맹목적으로 쓰지 않고, tool 기반 검증 구조를 갖춘다.

## 비목표

MVP 단계에서는 다음을 목표로 하지 않습니다.

- 모든 쇼핑몰 자동 크롤링
- 결제 자동화
- 사용자 체형 3D 모델링
- 실시간 가격 추적
- 완전 자동 구매 대행
- 패션 스타일링 전반 추천

## 성공 기준

- 최소 3개 후보 상품에 대해 분석 리포트를 생성할 수 있다.
- 사이즈표 이미지에서 주요 실측 값을 추출할 수 있다.
- 사용자가 등록한 기준 옷과 후보 상품의 차이를 수치로 보여줄 수 있다.
- 정보가 부족한 경우 "모름" 또는 "추가 확인 필요"로 처리한다.
- LLM 출력이 아니라 구조화된 근거를 기반으로 구매 판단을 설명한다.
